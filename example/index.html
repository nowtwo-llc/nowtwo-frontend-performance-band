frontendperformance band

A performance band editor for the browser. Labelled score thresholds, mastery flags and host colour tokens — rendered as form inputs inside your own form, with no save of its own.

  • v1.0.0
  • TypeScript
  • 0 dependencies
  • MIT

Try it

Type a new minimum and the list re-sorts around it without losing your place — a band's position is derived from its threshold rather than dragged, so reordering needs no mouse at all. The Covers column shows the span each band claims; it updates as its neighbours move.

The colour control is a swatch grid built into the library — no dependency, and fully operable from the keyboard: focus it and press ↓ to open, arrow around the grid, Enter to choose, Esc to back out. The four swatches are host theme tokens this page paints itself; the custom colour below them is switched on with allowCustomColor and is the one case the library paints inline.

What gets posted

This editor has no save button. It writes named inputs into the surrounding form and the host submits them, so the field names are a contract with your server. Press Show form data above to see exactly what the form would send — including a mastery_flg for every band, because an unchecked checkbox posts nothing and would shift every following flag onto the wrong band.

Install

npm install @nowtwo-llc/frontend-performance-band

Use

import { PerformanceBandEditor } from '@nowtwo-llc/frontend-performance-band';
import '@nowtwo-llc/frontend-performance-band/style.css';

const editor = new PerformanceBandEditor({
    container: '#nt-performance-band-app',
    bands: window._performanceBand
});

editor.mount();

Read the live bands back with editor.bands and the mastery tally with editor.masteryCount. Call destroy() to remove the DOM and every listener it registered.

Host integration

Everything page-specific goes through one HostBridge: icon markup, tooltip attributes, activation and dismissing tooltips. The default implementation reads a window.PerformanceBandHost object of that shape, which is exactly what this page defines in host.js — the whole reason the demo can run the real bundle with no application framework behind it.

  • Colour tokens are yours. The library stores and posts them; your stylesheet paints them. This page's .blue-base and friends are the whole integration.
  • Every bridge member is optional. Anything omitted degrades to a no-op, so the editor still renders and still posts correct form data on a page that provides nothing.
